# Карта параграфа — главный экран в стиле змейки

Дата: 2026-10-26. Статус: сделано, ждет проверки Дани.

## Секция 0. Принятые решения

- **Экран = один параграф.** Сверху синяя плашка с текущим параграфом; тап — список всех параграфов по главам, выбрать можно любой.
- **Змейка переменной длины**: Знакомство → Тест 1 → Тест 2 → Сундук → Тест 3 … Тест N → Контрольная. N зависит от объема параграфа: каждый факт (дата, термин, имя) должен встретиться ~3 раза, тест покрывает ~16 упоминаний; N от 3 до 8 (§19 — 3, §21–22 — 8). Формула в `testsFor()`.
- **Длинные параграфы делятся на части** по 3–5 тренировок (порог: больше 5 тренировок → резать). §21–22 → «·1 Столетняя война и Черная смерть» и «·2 Восстания, гуситы и конец войны». Деление живет в xlsx (лист «Параграфы», id вида `21-22a`), Даня может резать дальше сам.
- **Узлы без слов**: книжка — знакомство, звезда — тренировка, сундук, лист — контрольная; галочка — пройдено, корона — 100%. Слово «тест» в интерфейсе не используется, в речи персонажей — «тренировка». Подсказка по значкам — «?» у карты.
- **Провал тренировки** (меньше 70%) — на итогах кнопка «Повторить карточки» ведет на карточки именно этой тренировки.
- **Знакомство через подводки, а не через чтение** (решение 27.10): перед тренировками карточек нет. В первых трех тренировках параграфа часть заданий — «первые встречи» (5 → 3 → 2): ответ почти очевиден из контекста (пропуск в событии с датой, «термин — своими словами» с нелепыми дистракторами, «кто это, судя по всему»); каждый факт подводится один раз, через одно задание его спрашивают по-настоящему. Подводка не штрафует: половина XP, ошибка не идет в «ошибки». Первая тренировка параграфа открывает вторую при любом результате («ты только познакомился»).
- **Книжка** — не узел, а справочник сбоку от первого узла: весь параграф карточками в любой момент, без замка и галочки. «Повторить карточки» после провала остается.
- ~~Знакомство~~ (старое) — карточки всего материала параграфа (даты, термины, имена), ничего не спрашивают; карточки идут группами (даты, термины, имена) со счетчиком по группе; пройдено, когда долистал все. Перед каждым тестом — «подсмотреть» карточки только этого теста, без штрафа.
- Первые два теста без механик «порядок» и «напечатать» — только пары, выбор, правда/ложь, вставка.
- **Тест = 8 заданий.** Весь материал параграфа один раз случайно раскладывается по N тестам так, что каждый факт попадает в ~3 теста, каждый раз в другой механике. Раскладка фиксируется на ученика (localStorage).
- **До 100% (решение 27.10, как в Duolingo)**: после 8 заданий ошибочные возвращаются кругами, пока все не решены. Круг 1 — те же задания с легкой подсказкой (убран один вариант; первое событие в порядке на месте; в парах одна пара соединена; лишние слова убраны; у года — век). Круг 2 и дальше — почти очевидно (два варианта; все кроме двух; цифры года с пропуском; первая буква). Тренировка закрыта только по 100%; запоминается результат первого прохода. Корона — 100% с первого прохода. Подводки в доработку не идут. Пары: любая ошибка = задание не засчитано (раньше можно было подобрать перебором), после 3 ошибок показываем ответ. Внутри параграфа узлы открываются по очереди; сундук открыт всегда.
- **Сундук** = тренировка по прошлому параграфу (8 заданий). За 70% — +1 сердце на босса (максимум 3, награда за сундук один раз). В первом параграфе курса сундука нет.
- **Босс главы — отдельный экран** (дверь-домик на карте последнего параграфа главы: юрта для главы V, замок для VI). Три уровня: 1 Разминка (пары, правда-ложь, 10), 2 Как учитель спросит (порядок, вставка, причины, 10), 3 Босс (8 дат с клавиатуры, жизни = накопленные сердца, минимум 1). Следующий уровень от 70%. После третьего сердца сгорают.
- **Персонажи Опти, Ник, Душка** (js/characters.js, SVG-дудл, три эмоции, костюмы эпох по параграфам) — на стартовой, на карте у текущего узла, в заданиях и итогах. Стиль карты — каракули: кривые узлы, пунктирные дорожки, рукописный шрифт Caveat, легкий дудл-декор, тетрадная линейка.
- **Стартовая страница** — для тех, кто открыл ссылку впервые: три персонажа с репликами, кнопка «Начать». Логотип ведет на нее с карты.
- Старые «уроки» и «контрольная главы с тремя уровнями» убраны. Микс дня, XP, стрик — в шапке.
- Хранилище v3; из v2 переносятся XP, стрик, ошибки.
