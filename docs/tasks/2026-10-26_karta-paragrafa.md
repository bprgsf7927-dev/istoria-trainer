# Карта параграфа — главный экран в стиле змейки

Дата: 2026-10-26. Статус: сделано, ждет проверки Дани.

## Секция 0. Принятые решения

- **Экран = один параграф.** Сверху синяя плашка с текущим параграфом; тап — список всех параграфов по главам, выбрать можно любой.
- **Змейка из 7 узлов**: шаг 1 → шаг 2 → шаг 3 → 🎁 сундук → шаг 4 → шаг 5 → 📝 контрольная параграфа. После последнего параграфа главы — 🐲 босс главы. Внизу кнопка «Дальше: следующий параграф».
- **Шаг = 8 заданий.** Весь материал параграфа (даты, термины, имена) один раз случайно раскладывается по 5 шагам так, что каждый факт попадает в 2–3 шага, каждый раз в другой механике. Раскладка фиксируется на ученика (localStorage), чтобы шаг при повторе был тем же.
- **Пройден = 70%**, лучший результат обновляется при повторе. Внутри параграфа узлы открываются по очереди; сундук открыт всегда.
- **Сундук** = тренировка по прошлому параграфу (8 заданий). За 70% — +1 сердце на босса (максимум 3, награда за сундук один раз). В первом параграфе курса сундука нет.
- **Босс главы — отдельный экран** (дверь-домик на карте последнего параграфа главы: юрта для главы V, замок для VI). Три уровня: 1 Разминка (пары, правда-ложь, 10), 2 Как учитель спросит (порядок, вставка, причины, 10), 3 Босс (8 дат с клавиатуры, жизни = накопленные сердца, минимум 1). Следующий уровень от 70%. После третьего сердца сгорают.
- **Персонажи Опти, Ник, Душка** (js/characters.js, SVG-дудл, три эмоции, костюмы эпох по параграфам) — на стартовой, на карте у текущего узла, в заданиях и итогах. Стиль карты — каракули: кривые узлы, пунктирные дорожки, рукописный шрифт Caveat, легкий дудл-декор, тетрадная линейка.
- **Стартовая страница** — для тех, кто открыл ссылку впервые: три персонажа с репликами, кнопка «Начать». Логотип ведет на нее с карты.
- Старые «уроки» и «контрольная главы с тремя уровнями» убраны. Микс дня, XP, стрик — в шапке.
