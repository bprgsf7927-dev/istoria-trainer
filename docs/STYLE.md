# Стиль тренажера: «каракули в тетради»

Единый стиль для всех экранов. Новый элемент сначала сверяется с этим файлом, потом рисуется.

## Образ

Тетрадный лист в линейку, по которому рисовали ручкой. Все, что нарисовано, — нарочно криво: дрожащая линия, многоугольники вместо кругов, рамки с неровными углами, легкий наклон. Ничего глянцевого: без теней-объемов, градиентов, скругленных «айфонных» плашек и эмодзи в интерфейсе.

Референсы Алены: человечки-палочки с громкими эмоциями; плотный черно-белый дудл (облачка, лучики, зигзаги, заливки).

## Шрифты

- **Заголовки и названия** — Caveat (Google Fonts), 700: логотип, плашка параграфа, названия параграфов, «Шаг 1», заголовки заданий и итогов, кнопки-акценты («Погнали», «Начать»), подписи в списках.
- **Текст** — системный sans (-apple-system, Segoe UI, Roboto): формулировки заданий, варианты ответов, описания, подсказки. Читаемость важнее стиля.
- Ё не используем.

## Цвета

- Фон `#fbfbf8` + тетрадная линейка (`repeating-linear-gradient`, шаг 28px, `#e9ecf5`).
- Чернила `#1e2235` — рамки, узлы, дорожки, обычный текст. Приглушенный текст `#4f5663` (не светлее: сливается с декором).
- Акцент `#1F3FBF` (синяя ручка) — текущее, кнопки, Опти.
- Верно `#2f9e5b`, неверно `#D9480F` (цвет Ника), «почти» `#d9a400`.
- Душка `#3FA66A`, сундук `#c48a00`, контрольная `#7c5cff`, босс `#D9480F`.
- Декор-каракули `#a9b0c4`, прозрачность 0.35–0.65, только по краям экрана, никогда под текстом.

## Рамки и кнопки

Кривая рамка ручкой: `border: 2.5–3px solid #1e2235; border-radius: 255px 18px 225px 18px / 18px 225px 18px 255px` (или зеркальный вариант), `transform: rotate(±0.4–1.5deg)`, соседние элементы наклонены в разные стороны. Кнопка-акцент — та же рамка цветом акцента, текст Caveat. Нажатие — `scale(.97)` или легкий поворот, без «проваливания».

## Карта параграфа

Узлы — многоугольник `wobble()` в `js/app.js`, внутри иконка-каракуля из `DOODLE` (звезда, галочка, сундук, лист, кубок, замок-замочек, босс). Цвет узла по типу (см. цвета), закрытый — серый `#9aa0a6` с замочком. Между узлами — кривой пунктир `trailSVG()`. У текущего узла — персонаж в костюме эпохи (`charSVG(id, 'idle', topicId)`), покачивается.

## Персонажи

`js/characters.js`: Опти (синий), Ник (оранжевый), Душка (зеленый). Три эмоции: `idle`, `happy`, `upset`. Головы-многоугольники, глаза разного размера, линия 6px. Костюмы эпох в `COSTUMES` по id параграфа. Эмодзи вместо персонажей не используем.

Где стоят: стартовая (все трое), карта (у текущего узла), задания (реакция на ответ: верно — Опти happy, неверно — Ник upset, «почти» — Душка), итоги, список параграфов (по одному на карточку).

## Иконки и значки

Только рисованные SVG в стиле выше: корона `CROWN()` за 100%, сердца `HEART()`, иконки узлов `DOODLE`, домики боссов `BOSS_HOUSE` (юрта — глава V, замок — VI), иконка сайта — голова Опти. Звезда `STAR()` и огонек `FIRE()` в шапке — тоже нарисованные. Заливка цветных значков — косая штриховка ручкой (`HATCH`), не сплошная.

## Текст и тон

Коротко, по-русски, без «ё». Обратная связь всегда начинается явно: **Ты прав.** / **Ты не прав.** / **Почти.** Шутки и реплики персонажей — заготовки, Даня переписывает. Мотивирующие строки — в `PICKER_FOOT`, подсказки по значкам — в `HINTS`.

## Чего не делать

Градиенты, тени-объемы (`box-shadow` с offset), ровные круги, эмодзи в интерфейсе, серый текст светлее `#4f5663`, декор под текстом, новые шрифты, второй акцентный цвет.

## Нижняя панель

Неподвижная, на всех экранах кроме тренировки и стартовой: Карта, Книжка, События, Кабинет. Иконки-каракули, подписи Caveat, активная — акцентным цветом с наклоном. Крестика выхода из тренировки нет: выход через логотип с уговором Ника.
