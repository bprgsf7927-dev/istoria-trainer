# Истори-тренажер

Веб-тренажер по школьной истории. Проект Дани: он отвечает за стиль, персонажей и шутки, Алена — за техничку и контент, ассистент — за код.

Сейчас: История Средних веков, 6 класс (учебник Мединский, Чубарьян, 2025), главы V–VI.

## Запустить локально

Сайт статический, сборки нет. Но вопросы грузятся через `fetch`, поэтому открывать нужно через сервер, а не двойным кликом по файлу.

Терминал 2 (из папки проекта):

```bash
python3 -m http.server 3000
```

Открыть http://localhost:3000. На телефоне в той же Wi-Fi сети — `http://<ip-мака>:3000`.

## Структура

```
index.html                 — единственная страница
css/style.css              — стиль (пока минимальный белый, персонажи придут позже)
js/app.js                  — вся логика: темы, раунд, обратная связь, прогресс
content/srednie-veka-6/
  content.xlsx             — ИСТОЧНИК ПРАВДЫ: даты, термины, персоналии, причины, тексты, правда-ложь, уроки, главы
  *.json                   — генерируются из xlsx, руками не править
tools/xlsx2json.py         — xlsx → json (запускать после правки таблицы)
tools/build_content.py     — первичная сборка xlsx из авторского источника (разово)
assets/characters/         — SVG персонажей (пусто до выбора команды)
docs/tasks/                — спеки заданий, одна на этап: YYYY-MM-DD_тема.md
docs/BACKLOG.md            — что решили делать потом
manifest.webmanifest       — чтобы на телефоне добавлялось на главный экран
```

## Как добавлять и править контент

1. Открыть `content/srednie-veka-6/content.xlsx`, править нужный лист (легенда на первом листе). Столбец `id` не трогать.
2. В терминале из папки проекта: `python3 tools/xlsx2json.py`
3. Обновить страницу. Закоммитить и xlsx, и json.

Листы: Даты (с ассоциацией `assoc` и мини-фактом `more`), Термины, Персоналии, Причины, Тексты (пропуски `{0} {1} {2}`), Правда-ложь, Уроки (какие даты в каком уроке), Главы.

## Механики

Урок = 8 заданий: пары → выбор → порядок → вставить слово → правда/ложь → напечатать год → пары → выбор. Подготовка к контрольной по главе — три уровня (Разминка, Как учитель спросит, Босс с двумя жизнями), следующий открывается при 70%. Микс дня — 5 заданий из ошибок и давно не повторявшегося. Прогресс, XP и стрик — в браузере.

## Этапы

1. **Скелет**: механики, уроки, уровни подготовки, микс дня, карточки. Без аккаунтов. ✓ (ждет персонажей)
2. Персонажи выбранной команды, аккаунты и прогресс в облаке (Supabase), таблица для наполнения.
3. Шаринг: таблица лидеров, вызов другу.
4. Другие предметы.
